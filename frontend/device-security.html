Cybersecurity Topic

Device Security

Simple ways to protect computers, laptops, tablets, and other devices from common security threats.

Key Safety Points

🔄

Keep Software Updated

Install operating system, browser, and application updates to receive security fixes.

🔒

Use a Screen Lock

Protect your device with a strong password, PIN, or supported biometric security.

🛡️

Use Security Protection

Keep built-in security features enabled and use trusted security software when appropriate.

⬇️

Download From Trusted Sources

Install software from official websites or trusted application stores.

💾

Back Up Important Data

Keep backups of important documents and files so they can be recovered after data loss or device problems.

🚪

Lock Your Device When Away

Lock your computer or device whenever you leave it unattended, especially in shared spaces.

Common Device Security Mistakes

❌

Ignoring Updates

Delaying important security updates can leave known software weaknesses unpatched.

❌

Using Unknown USB Devices

Avoid connecting unknown USB drives or devices to your computer because they may contain harmful files.

❌

Installing Cracked Software

Avoid pirated or modified software because it may contain unwanted or malicious programs.

❌

Leaving Devices Unlocked

An unlocked device can allow someone nearby to access files, accounts, or personal data.

Quick Example

You are using a college computer and need to leave for a few minutes. Instead of leaving the computer unlocked, lock the screen before leaving.

Do & Don't

✅

Do

Update your device, use a screen lock, back up important files, and install software from trusted sources.

🚫

Don't

Do not install unknown software, use unknown USB devices, ignore security updates, or leave your device unlocked.

Quick Security Checklist

☑️

Before Installing

Confirm that the software comes from a trusted source.

☑️

Before Leaving

Save your work and lock the device.

☑️

Regularly

Check for updates and maintain backups of important files.

Remember

  • Keep software updated
  • Use a strong screen lock
  • Download from trusted sources
  • Back up important data
  • Lock devices when unattended

Quick Rule

Keep your device updated, protected, locked, and backed up.
